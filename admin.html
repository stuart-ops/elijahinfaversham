First time here? You need a key from GitHub. It only works on this one website, and you can delete it any time.
  1. Go to github.com token page
  2. Token name: elijah site editor
  3. Expiration: pick a date (you'll make a new one after)
  4. Repository access: Only select repositories → pick elijahinfaversham
  5. Permissions → Repository permissions → Contents → set to Read and write
  6. Click Generate token, copy it, paste below
